برای هر کسی که می‌خواهد چند کلیکی یک Worker + دیتابیس D1 با اسکیمای آماده بالا بیاورد (ربات، API کوچک، وب‌هوک، خودکارسازی…) و بعداً کد یا اسکیمایش را راحت عوض کند.

## ✨ چه کاری می‌کند؟

### 🚀 حالت «راه‌اندازی جدید»
فقط سه نام انتخاب کن — نام **Worker**، نام **دیتابیس D1** و نام **Binding** (مثلاً `DB`) — بقیه‌اش با این ابزار:

1. دیتابیس D1 ساخته می‌شود (اگر از قبل باشد، همان استفاده می‌شود — اجرای تکراری امن است)
2. فایل **schema.sql** آپلودی اتوماتیک روی دیتابیس اجرا می‌شود
3. کد **worker.js** آپلود می‌شود و D1 با نام Binding دلخواه به آن وصل می‌شود
4. **Variableها و Secretها** (مثل `BOT_TOKEN`) همان‌جا ست می‌شوند
5. آدرس **workers.dev** فعال و نمایش داده می‌شود (+ قالب آماده setWebhook برای ربات‌ها)

### ♻️ حالت «بروزرسانی»
Worker و دیتابیس **موجود** را از فهرست انتخاب کن و فقط چیزهایی را که می‌خواهی عوض کن:

- **کد جدید** Worker (جایگزین کامل کد قبلی)
- **اسکیمای جدید** روی دیتابیس (برای جدول/ستون‌های جدید — اجرای تکراری امن)
- **افزودن/تغییر Variable و Secret** — با `keep_bindings` مقادیر قبلی دست‌نخورده می‌مانند
- تغییر متغیرها **بدون تغییر کد** (PATCH تنظیمات)
- نمایش وضعیت فعلی Worker: compatibility_date + همه bindingها قبل از تغییر

## 🧰 امکانات

- 🔌 اتصال فقط با API Token — اکانت‌ها خودکار شمرده و انتخاب می‌شوند (Account ID اختیاری)
- 📱 آپلود فایل از گوشی، پیست کد، یا استفاده از `worker.js` همین ریپو
- 🔒 مدیریت Variable/Secret با یک دکمه (تغییر نوع V/🔒)
- 🧠 اجرای هوشمند SQL: اول یک‌جا؛ اگر خطا داد، دستور‌به‌دستور برای پیدا کردن دقیق دستور مشکل‌دار (فهم تریگر، رشته‌ها و کامنت‌ها)
- 🛡 گارد ایمنی: کد خالی/ناقص هرگز آپلود نمی‌شود تا Worker زنده‌ات خراب نشود
- ✅ گزارش گام‌به‌گام هر عملیات + راستی‌آزمایی bindingها بعد از آپلود
- 🇮🇷 پیام‌های خطای فارسی برای همه خطاهای رایج Cloudflare
- 🌐 رابط دوزبانه **فارسی / English** با یک کلید (جزئیات در پایین)
- 🔐 امنیت: توکن فقط در حافظه همین تب (sessionStorage) — هیچ‌جا ذخیره یا لاگ نمی‌شود

### 🆕 تازه‌ترین به‌روزرسانی (نسخه پنل ۲.۲)

- 🗂 **ورود فایل SQL درست شد**: علت اینکه «فایل JS می‌آمد ولی SQL نه» این بود که فیلتر `accept=".sql"` در فایل‌منیجر اندروید کار نمی‌کند (پسوند `.sql` هیچ MIME شناخته‌شده‌ای ندارد و خاکستری می‌شود). حالا فیلتر حذف شده، فایل‌های SQL با هر پسوندی انتخاب می‌شوند، BOM خودکار پاک می‌شود، فایل خالی/خراب با پیام روشن رد می‌شود و انتخاب دوباره‌ی همان فایل هم کار می‌کند
- 🖱 **کشیدن و رها کردن (drag & drop)**: فایل JS/SQL را می‌توانی مستقیم روی کادر متن بکشی و رها کنی (دسکتاپ) — کادر موقع کشیدن سبز و برجسته می‌شود
- 🌐 **زبان انگلیسی اضافه شد**: کلید شیشه‌ای 🌐 (فا/EN) در هدر — با یک لمس کل صفحه بین فارسی (RTL) و انگلیسی (LTR) با انیمیشن نرم جابه‌جا می‌شود؛ همه چیز ترجمه می‌شود: دکمه‌ها، راهنماها، پیام‌های خطا، دیالوگ‌های تایید و حتی گزارش اجرا. انتخاب زبان به‌خاطر سپرده می‌شود و فونت انگلیسی (Inter) جداگانه بارگذاری می‌شود
- 🗄 وقتی بخش «دیتابیس D1» را در تب بروزرسانی باز می‌کنی، لیست دیتابیس‌ها خودکار گرفته می‌شود (یک کلیک کمتر برای اجرای SQL)
- 🧩 سایر اصلاح‌ها: راهنمای پل با تعویض زبان تازه می‌شود، تاریخ/ساعت گزارش در حالت انگلیسی با فرمت انگلیسی نمایش داده می‌شود

### به‌روزرسانی قبلی (نسخه پنل ۲.۱)

- ✍️ **هشدار و اصلاح زنده نام Worker**: کلادفلر زیرخط (`_`)، فاصله، حروف بزرگ و فارسی را در نام Worker نمی‌پذیرد — کادر نام، هم‌زمان با تایپ همه را خودکار اصلاح و توضیح می‌دهد (برای ورکرهای قدیمی، اگر نام دقیق در اکانت موجود باشد همان استفاده می‌شود)
- 🪝 **وب‌هوک بی‌نقص**: مسیر پیش‌فرض = ریشه ورکر (`/`) — دیگر `/webhook` تحمیلی که ربات را قطع می‌کرد وجود ندارد؛ قبل از تنظیم، ورکر زنده بودن را هم چک می‌کند (تست شبکه + بررسی وجود ورکر در اکانت از طریق API)، بعد از تنظیم با `getWebhookInfo` تایید می‌شود؛ دکمه‌های «قطع وب‌هوک»، «دستور دستی» و گزینه `drop_pending_updates` اضافه شد
- 🧰 **تب جدید «ابزارها»**: مدیریت کامل **Cron Triggers** (نمایش/افزودن/حذف/ذخیره با پیش‌تنظیم‌های آماده) + **عیب‌یابی** (تست سلامت ورکر با اندازه‌گیری تأخیر، وضعیت ربات و وب‌هوک با نمایش آخرین خطای پلتفرم، لینک مستقیم صفحه ورکر و لاگ‌ها در داشبورد کلادفلر)
- 🎨 خوانایی بهتر: کنتراست بیشتر در حالت روشن و تاریک، فونت بزرگ‌تر ورودی‌ها روی موبایل (بدون زوم iOS)، چینش ۲×۲ تب‌ها در صفحه کوچک، گزارش اجرا با زمان و دکمه کپی
- 🔗 کارت لینک‌های کانال پیشنهادات + بات پشتیبانی + ربات فروشگاه (بالای صفحه و فوتر)

## 🧩 API داخلی (برای توسعه‌دهنده‌ها)

| مسیر | کار |
|---|---|
| `POST /api/cf/verify` | اعتبارسنجی توکن + لیست اکانت‌ها |
| `POST /api/cf/resources` | لیست Workerها و دیتابیس‌های D1 |
| `POST /api/cf/worker-info` | تنظیمات یک Worker (compat date + bindingها) |
| `POST /api/cf/d1` | ساخت دیتابیس D1 (اگر موجود بود، همان برمی‌گردد) |
| `POST /api/cf/sql` | اجرای اسکریپت SQL روی D1 (یک‌جا / تکه‌ای با گزارش خطا) |
| `POST /api/cf/deploy` | آپلود کد + Variable/Secret + اتصال D1 + workers.dev |
| `GET /api/worker-code` | سرو محتوای `worker.js` همین ریپو |
