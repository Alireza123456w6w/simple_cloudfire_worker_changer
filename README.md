# 🛒 ربات فروشگاه بله / تلگرام — کد Worker + پنل دیپلوی خودکار

این ریپو دو بخش دارد که کنار هم کار می‌کنند:

| بخش | فایل | توضیح |
|---|---|---|
| 🤖 کد ربات | `worker.js` | کد Cloudflare Worker — **الان خالی است**؛ کد کامل (نسخه ۷.۳) را داخلش جای‌گذاری کن |
| 🖥 پنل دیپلوی | `src/` | سایت کمکی Next.js که `worker.js` را **بدون کپی‌پیست** و یک‌کلیکی به Cloudflare آپلود می‌کند |
| 🗄 دیتابیس | `setup.sql` | اسکیمای کامل D1 (۸ جدول + داده اولیه) — اجرای تکراری بی‌خطر |

نسخه ورکر: **۷.۳** — چند-پلتفرمی (بله 🟡 + تلگرام)، پرداخت آنلاین کیف پول بله (sendInvoice)، کارت‌به‌کارت با چرخش کارت، سفارش چندپیامی، رسید عکسی، امتیازدهی، درخواست آپدیت/تغییر، و حالت «فقط پرداخت آنلاین» وقتی هیچ کارتی فعال نباشد.

---

## 🚀 شروع سریع (اجرای پنل)

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کن. (نیازمندی: Node.js نسخه ۲۰ به بالا)

---

## 📝 قدم ۱ — جای‌گذاری کد ورکر در `worker.js`

کد کامل ورکر را از دستیار بگیر و **تمام محتوای** `worker.js` ریشه را با آن جایگزین کن.

روی خود گیت‌هاب هم می‌شود (مناسب موبایل):

1. فایل `worker.js` را باز کن → آیکون ✏️ (Edit)
2. همه متن را Select All → حذف → کد جدید را Paste کن
3. Commit changes

> ⚠️ **گارد ایمنی:** تا وقتی `worker.js` خالی (placeholder) باشد، دکمه «دیپلوی خودکار» پنل عمداً خطای راهنما می‌دهد تا کد واقعی ورکرت روی Cloudflare با یک فایل خالی خراب نشود.

---

## ☁️ قدم ۲ — آماده‌سازی Cloudflare (فقط بار اول)

1. **Worker** بساز (مثلاً با نام `balebot`) — یک بار Deploy خالی بزن
2. **D1** بساز → `setup.sql` را در Console دیتابیس اجرا کن
3. دیتابیس را به Worker وصل کن: Settings → Bindings → D1 → نام binding دقیقاً `DB`
4. این متغیرها را اضافه کن:

| نام | نوع | مقدار | لازم؟ |
|---|---|---|---|
| `PLATFORM` | Variable | `bale` (یا `telegram`) | ✅ |
| `BOT_TOKEN` | Secret | توکن بات از BotFather | ✅ |
| `ADMIN_CHAT_ID` | Variable | چت‌آیدی ادمین — با `/id` در ربات بگیر | ✅ |
| `WALLET_TOKEN` | Secret | توکن پرداخت کیف پول بله | برای پرداخت آنلاین |
| `CHANNEL_HANDLE` | Variable | مثل `@o_p_Products` | اختیاری |
| `SUPPORT_HANDLE` | Variable | یوزرنیم پشتیبانی | اختیاری |
| `SITE_URL` | Variable | آدرس سایت‌ات | اختیاری |

## ⚡ قدم ۳ — دیپلوی خودکار (پیشنهادی)

در پنل، بخش «دیپلوی خودکار»:

1. **Account ID** — از نوار آدرس داشبورد Cloudflare کپی کن
2. **API Token** — از My Profile → API Tokens با قالب **Edit Cloudflare Workers** بساز
3. **Worker Name** — نام ورکر (پیش‌فرض `balebot`)
4. دکمه دیپلوی را بزن ✅

پنل خودش این کارها را می‌کند:
- اعتبارسنجی توکن و Account ID با پیام خطای فارسی
- آپلود `worker.js` ریشه پروژه به Cloudflare
- **حفظ همه Variableها / Secretها / اتصال D1** (با `keep_bindings`) + راستی‌آزمایی بعد از آپلود و گزارش
- وبهوک ربات دست نمی‌خورد

🔒 توکن API **ذخیره نمی‌شود** — فقط همان لحظه در حافظه استفاده می‌شود.

## 🔄 آپدیت‌های بعدی

کد جدید آمد؟ فقط دو قدم:

1. `worker.js` را عوض کن (ویرایش وب گیت‌هاب روی موبایل هم راحت است)
2. پنل → دکمه دیپلوی خودکار

پنل `accountId` و نام ورکر را در همان مرورگر نگه می‌دارد؛ دفعه بعد فقط توکن (و حتی آن هم در همان تب برای بار بعد) کافی است.

## 🌍 قرار دادن پنل روی Vercel (اختیاری)

ریپو را در Vercel Import کن — تنظیمات خاصی نمی‌خواهد، همان بیلد پیش‌فرض Next.js کار می‌کند. فایل `worker.js` با تنظیم `outputFileTracingIncludes` در `next.config.ts` همراه توابع سروری بسته‌بندی می‌شود.

> 🔒 توصیه: ریپو را **Private** نگه دار — هم کد ربات‌ات بعداً اینجا می‌نشیند، هم پنل ابزار دیپلوی است.

---

## 🧷 روش‌های دیگر رساندن کد به Cloudflare

- **کپی دستی:** محتوای `worker.js` را در ادیتور Cloudflare (Edit code) Paste و Deploy کن — Bindings دست نمی‌خورد
- **پیشرفته (اتصال گیت به Cloudflare):** `wrangler.jsonc.example` را به `wrangler.jsonc` تغییر نام بده، `database_id` واقعی D1 و بقیه مقادیر را بگذار، سپس از Workers Builds استفاده کن — داخل همان فایل مرحله‌به‌مرحله توضیح داده‌ام
